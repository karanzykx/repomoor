## Evidence discipline

We do not import promotional author-reported percentages as measured RepoMoor savings. Independent user reports and forum comparisons discussed in the original research are informative but not sufficient for a tool's acceptance gate. If a number enters the README, add the test harness, source/version, observed metric denominator, and reproducible result artifact first.
