# Community code of conduct

RepoMoor welcomes constructive, technical collaboration. Be respectful of contributors and their differing tools, experience and constraints. Avoid harassment, discriminatory remarks, personal attacks, doxxing, or sharing private project configurations without permission. Discuss the merits of a proposed tool or benchmark using reproducible evidence rather than personal criticism.

Maintainers may remove content or restrict participation to protect the community. To report a concern, use the private maintainer contact mechanism provided in the GitHub repository when one has been configured. No private contact address has been set in this initial template; do not publish a fabricated email address.
